## 📖 Overview

**TypeByAman** is a lightweight, local typing and code reproduction tool developed by **Aman Kumar**. It allows you to paste code or text and watch it type out smoothly character-by-character directly into your active VS Code editor window.

It is ideal for:
- 🎥 **Coding Demonstrations & Videos** — Produce clean, realistic typing for YouTube, TikTok, Reels, or online courses.
- 📚 **Programming Tutorials** — Present code gradually to give learners time to absorb each concept.
- 🎓 **Classroom & Conference Presentations** — Deliver live-like presentations without unexpected live-typing errors.
- 🧪 **Testing & Quality Assurance** — Verify editor events, extensions, and text-buffer handling.
- 🔒 **100% Local & Private** — Runs entirely inside your local VS Code environment with zero network requests and zero tracking.

---

## ✨ Features

- **Integrated WebView Control Panel**: Visual dashboard to enter text, pick speeds, and track real-time progress.
- **Configurable Typing Speeds**:
  - *Very Slow*: ~15 WPM (150 ms/char)
  - *Slow*: ~35 WPM (75 ms/char)
  - *Normal*: ~60 WPM (45 ms/char)
  - *Fast*: ~95 WPM (25 ms/char)
  - *Very Fast*: ~140 WPM (12 ms/char)
  - *Custom*: 1 to 9999 ms per character
- **Full Formatting Fidelity**: Accurately preserves indentation, multi-line blocks, tabs, Unicode symbols, and emojis.
- **Status Bar Integration**: Displays current typing state, character count, percentage completed, and live typing speed.
- **Full Playback Controls**: Start, Pause, Resume, Stop, and Restart at any point.

## ⌨️ Commands & Shortcuts

Access these commands anytime from the **Command Palette** (`Ctrl + Shift + P` or `Cmd + Shift + P`):

| Command | Shortcut | Description |
|---|---|---|
| `TypeByAman: Open Control Panel` | `Alt + Shift + O` | Opens the interactive visual control panel |
| `TypeByAman: Start Typing Replay` | `Alt + Shift + S` | Begins typing text into the active editor |
| `TypeByAman: Pause` | `Alt + Shift + P` | Pauses typing playback |
| `TypeByAman: Resume` | `Alt + Shift + R` | Resumes paused typing playback |
| `TypeByAman: Stop` | `Alt + Shift + X` | Stops typing playback immediately |
| `TypeByAman: Restart` | `Alt + Shift + K` | Restarts typing from the beginning |
| `TypeByAman: Configure Speed` | — | Select a speed preset or define custom ms delay |

## 🚀 Quick Start Guide

1. Open any file in VS Code or create a new file (`Ctrl + N`).
2. Press `Ctrl + Shift + P` and run:
   ```text
   TypeByAman: Open Control Panel
   ```
3. Paste or write the text/code you want to reproduce.
4. Select your desired typing speed.
5. Click **Start Typing** — focus will automatically switch to your editor and begin typing!
